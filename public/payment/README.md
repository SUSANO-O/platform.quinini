# Logos de medios de pago

Coloca aquí los SVG oficiales con EXACTAMENTE estos nombres (todo minúscula):

- `nequi.svg`
- `daviplata.svg`
- `pse.svg`
- `bre-b.svg`

La página /pricing los detecta automáticamente: si el archivo existe, muestra el
logo real; si no, cae a un badge de color con icono genérico (no se rompe).

## Dónde descargarlos (oficiales / vector)

- Nequi: https://worldvectorlogo.com/logo/nequi-2  ·  https://brandfetch.com/nequi.com
- Daviplata: https://worldvectorlogo.com/logo/daviplata  ·  https://seeklogo.com/vector-logo/423084/daviplata
- PSE: https://worldvectorlogo.com/logo/pse  ·  https://brandfetch.com/pse.com.co
- Bre-B: https://www.banrep.gov.co/es/bre-b/manual-identidad-visual (caja de herramientas / sello)

Sugerencia: que sean SVG con el logo recortado (sin mucho margen) para que se vean
parejos. Alto de referencia en la UI: ~22px.
